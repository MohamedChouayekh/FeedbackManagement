# FeedbackManagement

**Projet de stage chez Acteol —août 2025**

## Présentation

FeedbackManagement est une application web développée dans le cadre de mon stage chez Acteol. Le projet porte sur la gestion des retours clients et leur exploitation à travers une interface de suivi.

## Technologies utilisées

- **Langage :** C#
- **Framework :** ASP.NET MVC 5
- **Base de données :** SQL Server
- **Accès aux données :** Entity Framework

## Fonctionnalités

- Gestion des retours clients
- Tableau de bord avec indicateurs statistiques
- Filtrage et visualisation des données

## Objectif du projet

Mettre en pratique le développement d'applications web, l'accès aux données relationnelles et la création d'interfaces de suivi.

*Projet réalisé dans un contexte de stage. Toute diffusion publique du code et des éléments associés doit respecter les autorisations applicables.*
